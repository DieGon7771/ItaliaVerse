Come si installano?

Aggiungere un repository a CloudStream richiede un attimo: scegli il metodo che preferisci.

Metodo veloce

Consigliato

Clicca il pulsante Installa per installare la repo direttamente nell'app.

Vai ai repository

Metodo manuale

Vai in Impostazioni→Estensioni→Aggiungi repository e inserisci lo shortcode o il link del repository.

Dopo l’installazione

Entra nella repo e installa i plugin che preferisci.

Se alcuni non funzionano

Prova a:

  • cambiare DNS dalle impostazioni dell’app (consigliato Cloudflare o AdGuard)
  • installare la versione prerelease
  • aggiornare manualmente il plugin
